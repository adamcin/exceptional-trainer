# Exercise: Puppet Warp for Organic Adjustments

## Learning Objective

Master Puppet Warp for organic, natural-looking deformations.

## What is Puppet Warp?

Edit > Puppet Warp: Places mesh over image, add pins, move pins to deform image naturally.

**Use cases**:
- Adjust body positions
- Change head tilt subtly
- Fix minor perspective issues
- Organic pose adjustments

## Part 1: Puppet Warp Basics

1. Select layer
2. Edit > Puppet Warp
3. Mesh appears
4. Click to place pins (anchor points)
5. Drag pins to deform

**Pin strategy**:
- Pin areas that should NOT move (anchors)
- Pin areas that SHOULD move (manipulation points)
- More pins = more control, less natural movement

## Part 2: Head/Neck Adjustment

Typical scenario: Head angle slightly off.

**Workflow**:
1. Puppet Warp on head layer
2. Place pins:
   - Base of neck (anchor—shouldn't move)
   - Shoulders (anchors)
   - Chin or forehead (manipulation point)
3. Drag manipulation point to adjust angle
4. Subtle adjustments only!

## Part 3: Options

**Mode**:
- Normal: Standard deformation
- Rigid: Maintains structure more (good for heads)
- Distort: More flexible

**Density**:
- Fewer Points: Faster, less control
- More Points: Slower, more control

**Expansion**: Extends mesh beyond layer edges

## Part 4: Rotation

**Pin rotation**:
Alt/Option + hover near pin = rotation handle
Rotate section around pin

**Use**: Twist or rotate specific areas independently.

## Part 5: Pin Management

**Add pin**: Click
**Remove pin**: Select pin, press Delete
**Show mesh**: Checkbox in options bar
**Pin depth**: If pins overlap, right-click > pin depth (forward/backward)

## Verification Checklist

- [ ] Can activate Puppet Warp
- [ ] Can place and move pins
- [ ] Can use pins to make subtle organic adjustments
- [ ] Understand pin strategy (anchors vs. manipulation)
- [ ] Can use for head angle adjustments
- [ ] Results look natural, not distorted
