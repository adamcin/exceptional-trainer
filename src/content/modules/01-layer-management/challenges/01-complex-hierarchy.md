# Challenge: Build a Complex Document Structure

## Objective

Create a well-organized, professional layer structure for a multi-subject composite image, demonstrating real-world organizational skills.

## Scenario

You're beginning work on a simplified version of your satirical project: a composite image with 5 historical figures whose heads you'll replace. Set up the layer structure BEFORE doing any actual compositing.

## Requirements

### Document Setup
- Canvas size: 3000x2000px
- Color mode: RGB
- Import a historical painting or create placeholder background

### Layer Structure Requirements

Your document must include:

1. **Background Group**
   - Original painting layer
   - Background adjustments layer (curves/levels)
   - Backup copy (hidden)

2. **Five Figure Groups** (one per subject)
   Each group must contain:
   - Original figure area (for reference)
   - Head replacement smart object
   - Layer mask for blending
   - Color correction adjustment layer
   - Shadow layer
   - Highlight layer

3. **Global Adjustments Group**
   - Overall color grade
   - Vignette
   - Grain/texture
   - Final sharpening (placeholder)

4. **Reference & Notes Group**
   - Text layer with figure identification
   - Guides and markers
   - Progress tracking notes

### Naming Convention

Apply consistent naming:
- Prefix each layer type (BG_, FIG_, ADJ_, FX_, REF_)
- Number figures 01-05
- Describe purpose clearly
- Example: `FIG_03_Head_Mask_Refined`

### Color Coding System

- **Red**: Original/untouched content
- **Yellow**: Active work in progress
- **Green**: Completed and approved
- **Blue**: Adjustments and corrections
- **Purple**: Effects and finishing touches
- **Orange**: Reference and notes

### Smart Object Setup

- Each head replacement must be a smart object
- Name smart objects descriptively
- Include placeholder images (can be simple shapes)
- Demonstrate you understand linked vs. independent copies

## Success Criteria

- [ ] Document has exactly 5 figure groups with complete structure
- [ ] Every layer follows the naming convention
- [ ] Color coding is applied consistently throughout
- [ ] All figure groups use smart objects for head replacements
- [ ] Groups are properly nested (no more than 3 levels deep)
- [ ] Background layers are locked
- [ ] Reference materials are in a separate group
- [ ] You can navigate to any layer in under 5 seconds
- [ ] Total layer count: 40-50 layers (properly organized)
- [ ] Document saves without errors

## Challenge Extensions

### Bonus Challenge 1: Layer Comps
Create 3 layer comps showing:
1. Original painting only
2. Work in progress (some heads replaced)
3. Final composite (all heads replaced)

### Bonus Challenge 2: Template Creation
Save this as a template you can reuse:
- File > Save As > Photoshop Template (.pst)
- Clean out any specific content
- Keep the structure and naming

### Bonus Challenge 3: Scripting Prep
Organize your layers in a way that would support batch processing:
- Consistent naming allows scripting
- Predictable structure enables automation
- Think: "Could a script find all my head layers?"

## Evaluation

Grade yourself honestly:

**Excellent (90-100%)**:
- Structure is immediately intuitive to a stranger
- Naming is clear and consistent
- Color coding provides instant visual navigation
- Smart objects are properly configured
- Would scale to 47 figures easily

**Good (75-89%)**:
- Structure is logical with minor inconsistencies
- Most layers are well-named
- Color coding mostly consistent
- Smart objects work but could be better organized

**Needs Improvement (<75%)**:
- Structure is confusing or inconsistent
- Many generic layer names remain
- Color coding missing or random
- Smart objects not utilized effectively

## Time Limit

45 minutes (structure only, no actual compositing)

## Hints

- Sketch your structure on paper first
- Create one perfect figure group, then duplicate it
- Use Command/Ctrl + J to duplicate groups
- Remember: Organization now saves hours later
- Think scalability: 5 figures today, 47 tomorrow

## Submission Checklist

Before considering this challenge complete:

- [ ] Screenshot your Layers panel (fully expanded)
- [ ] Screenshot your Layers panel (with groups collapsed)
- [ ] Verify you can find any layer within 5 seconds
- [ ] Test: Close and reopen—still makes sense?
- [ ] Ask: "Would I understand this structure in 6 months?"
