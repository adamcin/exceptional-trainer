# Challenge: Create Atmospheric Depth

## Objective

Create composite with multiple subjects at different depths, using atmospheric perspective for distance realism.

## Atmospheric Perspective

Distant objects appear:
- Less saturated
- Lower contrast
- Slightly blue/cool tint
- Less sharp/detailed
- Lighter in value

## Requirements

Create composite with 3 subjects:
- **Foreground**: Full saturation, contrast, sharpness
- **Midground**: Moderate reduction
- **Background**: Significant reduction (atmospheric haze)

## Tasks

1. Position subjects at different depths
2. Apply appropriate adjustments to each:
   - Foreground: Minimal adjustment
   - Midground: Reduce saturation 20%, contrast 15%, slight cool shift, slight blur
   - Background: Reduce saturation 40%, contrast 30%, cool shift, more blur
3. Ensure consistent lighting direction
4. Add shadows appropriately
5. Create believable depth illusion

## Success Criteria

- [ ] Clear depth separation between subjects
- [ ] Atmospheric perspective correctly applied
- [ ] Lighting consistent across all subjects
- [ ] Realistic spatial relationships
- [ ] Creates convincing depth illusion
- [ ] Completed under 45 minutes

## Time: 45 minutes
