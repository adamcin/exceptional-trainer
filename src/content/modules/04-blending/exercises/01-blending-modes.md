# Exercise: Blending Mode Mastery

## Learning Objective

Master all blend modes to create sophisticated layer interactions and effects.

## Blend Mode Categories

**Darken Group**: Darken, Multiply, Color Burn, Linear Burn, Darker Color
- Creates darker results
- **Multiply**: Most common, darkens like ink layers

**Lighten Group**: Lighten, Screen, Color Dodge, Linear Dodge, Lighter Color
- Creates lighter results
- **Screen**: Most common, lightens like projected light

**Contrast Group**: Overlay, Soft Light, Hard Light, Vivid Light, Linear Light, Pin Light, Hard Mix
- Increases contrast
- **Overlay/Soft Light**: Most useful, enhances contrast while preserving mid-tones

**Comparative Group**: Difference, Exclusion, Subtract, Divide
- Mathematical comparisons, creative effects

**Color Group**: Hue, Saturation, Color, Luminosity
- Separates color from tone
- **Color**: Apply color without changing brightness
- **Luminosity**: Apply brightness without changing color

## Setup

Practice layers: Image, solid color fill, gradient, texture.

## Part 1: Essential Blend Modes

### Multiply (Shadows and Darkening)

**Use**: Create shadows, darken images, composite dark elements
1. Create layer above image
2. Paint with dark gray/black
3. Set to Multiply
4. Result: Darkens underlying image

**Your project**: Shadow layers under heads

### Screen (Highlights and Lightening)

**Use**: Add highlights, lighten images, composite light effects
1. Create layer
2. Paint with light colors
3. Set to Screen
4. Result: Lightens underlying image

**Your project**: Edge highlights on heads from candle glow

### Overlay (Contrast and Color Enhancement)

**Use**: Add contrast, enhance colors, blend textures
1. Duplicate image layer
2. Set to Overlay
3. Instant contrast boost

**Your project**: Add texture overlays to match painting aesthetic

### Soft Light (Gentle Contrast)

**Use**: Subtle lighting effects, gentle dodge/burn
1. Create layer, fill with 50% gray
2. Set to Soft Light
3. Paint white (dodge), black (burn)
4. Non-destructive lighting adjustments

**Your project**: Refine lighting on head surfaces

### Color (Apply Color Without Changing Tone)

**Use**: Color grade, change colors while preserving detail
1. Create layer
2. Paint colors or apply gradient
3. Set to Color blend mode
4. Colorizes without affecting brightness

**Your project**: Quick color adjustments to match painting palette

### Luminosity (Apply Tone Without Changing Color)

**Use**: Adjust brightness while preserving colors
1. Adjustment layer
2. Set to Luminosity
3. Affects brightness only

**Your project**: Match tonal values while keeping color intact

## Part 2: Practical Applications

### Shadow Creation

1. Duplicate head layer
2. Fill with black (Shift + F5, black, 100%)
3. Set to Multiply (60-80% opacity)
4. Transform: Perspective transform to match light direction
5. Blur: Gaussian Blur (varies with distance)
6. Mask where shadow shouldn't fall

### Highlight Creation

1. New layer
2. Paint white along lit edges
3. Set to Screen (20-40% opacity)
4. Gaussian Blur slightly (0.5-2px)

### Texture Overlay

1. Place texture layer
2. Desaturate (Command/Ctrl + Shift + U)
3. Set to Overlay or Soft Light
4. Adjust opacity (20-50%)

### Color Grading

1. Gradient Map adjustment or solid color layer
2. Set to Color blend mode
3. Apply unified color treatment
