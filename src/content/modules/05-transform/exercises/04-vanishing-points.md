# Exercise: Working with Vanishing Points

## Learning Objective

Use vanishing points and guides to match perspective perfectly.

## Part 1: Finding Vanishing Points

In background image:

1. Identify parallel lines that recede into depth
2. Draw guide lines extending those lines
3. Where they converge = vanishing point
4. Use Guides (View > New Guide) or Line tool for visualization

**Technique**:
- Create new layer
- Line tool or pen tool
- Trace major perspective lines
- Extend to find convergence

## Part 2: Using Vanishing Point Filter

Filter > Vanishing Point: Special workspace for perspective-aware editing.

**Workflow**:
1. Filter > Vanishing Point
2. Create Plane tool: Define perspective grid on background
3. Click 4 corners of known plane (wall, floor, etc.)
4. Grid adjusts to match perspective
5. Can clone, paste, paint in perspective
6. OK to apply

**Limitations**: Works best with clear geometric surfaces.

## Part 3: Manual Perspective Matching

Without Vanishing Point filter:

1. Identify horizon line
2. Find vanishing points
3. Transform subject to align with perspective:
   - Perspective Transform
   - Adjust until subject's implied lines converge to same vanishing points

**Verification**: Draw guide lines from subject edges—should converge to background vanishing points.

## Part 4: Head Replacement Perspective

For head on body:

1. Identify body's viewing angle
   - Is viewer looking up, down, or level?
   - What's the horizon line relative to body?
2. Match head's viewing angle
   - If looking up at body, should see under chin
   - If looking down, should see top of head
3. Subtle Perspective Transform or Puppet Warp

**Most figures in Declaration of Independence**: Relatively neutral viewing angles, but some variation.

## Verification Checklist

- [ ] Can find vanishing points in images
- [ ] Can use guides to visualize perspective
- [ ] Can use Vanishing Point filter (basics)
- [ ] Can manually match perspective with transforms
- [ ] Can assess if subject matches background perspective
- [ ] Can apply to head replacement scenarios
