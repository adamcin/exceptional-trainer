I have set a personal goal to use Adobe Photoshop to create a satirical variation of the painting titled, "Declaration of Independence", which has a page on Wikipedia that you can read for reference: [https://en.wikipedia.org/wiki/Declaration_of_Independence_(painting)]. The concept I have for the new work involves replacing the heads of many of the figures with the head of Elon Musk, while matching the size, position, and orientation of the original head, and ensuring that the replacement is integrated seamlessly into the surrounding image according to the style of the original artist, John Trumbull. However, I lack the knowledge and expertise as a Photoshop user to execute on this goal, and instead of having an agent create the described satirical image directly, what I really need agents to design and build for me is a companion web application that offers a skills-based curriculum for me to follow along in Photoshop, with exercises, challenges, and assessments, that upon successful completion, will demonstrate that I have achieved a sufficient level of expertise in Adobe Photoshop to carry out my vision for the satirical work. The current directory is the git repository in which this web application should be developed. The project name is Exceptional Trainer. Please use vite, typescript, and Adobe spectrum web components.
