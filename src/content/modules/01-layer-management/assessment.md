# Module Assessment: Advanced Layer Management

Complete this self-assessment to verify you've mastered the concepts in this module. Be honest with yourself—these skills are foundational for your project's success.

## Instructions

1. Work through each criterion in Photoshop
2. Mark each as Pass or Fail based on your ability
3. You must pass 8/10 criteria (80%) to proceed to the next module
4. If you fail, review the relevant exercises and try again

## Assessment Criteria

### 1. Layer Organization

**Task**: Open a document with 30+ unorganized layers and organize them into logical groups.

**Success Criteria**:
- [ ] Layers are grouped by function (background, subjects, effects, text)
- [ ] Groups are nested no more than 3 levels deep
- [ ] Layer panel is scannable and navigable
- [ ] You can find any layer within 5 seconds

**Pass/Fail**: _____

---

### 2. Naming Conventions

**Task**: Rename all layers in a document using a professional naming convention.

**Success Criteria**:
- [ ] Every layer has a descriptive name (no "Layer 1" or generic names)
- [ ] Naming follows consistent pattern with prefixes or suffixes
- [ ] Sequential elements are numbered consistently (01, 02, not 1, 2)
- [ ] Names describe purpose, not just content ("Head_ColorMatch" not "adjustment")

**Pass/Fail**: _____

---

### 3. Color Coding System

**Task**: Apply a color coding system to a complex document.

**Success Criteria**:
- [ ] Colors are applied consistently according to a defined system
- [ ] Different layer types have different colors
- [ ] Color coding provides immediate visual navigation benefit
- [ ] Can explain your color system to someone else

**Pass/Fail**: _____

---

### 4. Smart Object Creation

**Task**: Convert layers to smart objects appropriately.

**Success Criteria**:
- [ ] Can convert single layer to smart object
- [ ] Can convert multiple layers to single smart object
- [ ] Understands when to use vs. not use smart objects
- [ ] Smart objects are named descriptively

**Pass/Fail**: _____

---

### 5. Smart Object Editing

**Task**: Edit smart object contents and see changes propagate.

**Success Criteria**:
- [ ] Can double-click to open smart object for editing
- [ ] Can make changes and save embedded document
- [ ] Understands that main document updates automatically
- [ ] Can identify which layers are smart objects visually

**Pass/Fail**: _____

---

### 6. Non-Destructive Transformations

**Task**: Transform a smart object multiple times without quality loss.

**Success Criteria**:
- [ ] Can scale smart object down and back up without quality loss
- [ ] Understands why smart objects preserve quality
- [ ] Can demonstrate quality difference vs. regular layer
- [ ] Knows how to reset transformations if needed

**Pass/Fail**: _____

---

### 7. Linked vs. Independent Smart Objects

**Task**: Create both linked and independent smart object copies and explain the difference.

**Success Criteria**:
- [ ] Can create linked duplicates (Alt/Option + drag)
- [ ] Can create independent copies (New Smart Object via Copy)
- [ ] Understands when to use each type
- [ ] Can demonstrate that linked copies update together

**Pass/Fail**: _____

---

### 8. Smart Filters

**Task**: Apply filters non-destructively using smart filters.

**Success Criteria**:
- [ ] Can apply filter to smart object
- [ ] Filter appears as smart filter (editable)
- [ ] Can modify filter settings after application
- [ ] Can toggle filter visibility or delete it

**Pass/Fail**: _____

---

### 9. Layer Protection

**Task**: Lock layers appropriately to prevent accidental changes.

**Success Criteria**:
- [ ] Can apply full lock to finished layers
- [ ] Can apply position lock to allow painting but not movement
- [ ] Understands when to lock vs. not lock layers
- [ ] Has locked background and reference layers

**Pass/Fail**: _____

---

### 10. Scalable Structure

**Task**: Create a layer structure that could scale from 5 to 47 elements.

**Success Criteria**:
- [ ] Structure is consistent and repeatable
- [ ] Group template can be duplicated easily
- [ ] Naming system supports large numbers
- [ ] Organization doesn't break down with many elements

**Pass/Fail**: _____
