# Challenge: Create Unified Color Palette

## Objective

Demonstrate comprehensive color matching mastery by taking 3+ subjects from different sources and creating a unified color palette that makes them appear photographed together.

## Scenario

You have 3 portrait photos from different photographers, different lighting setups, different cameras. Composite them into one scene with perfectly matched colors—as if they were always together.

This simulates your satirical project: Multiple Elon Musk photos (different sources) composited into one 1818 painting.

## Requirements

### Source Images

Collect 3-5 portrait photos with:
- **Different lighting** (daylight, studio, indoor, etc.)
- **Different color temperature** (warm, cool, neutral)
- **Different saturation levels**
- **Good resolution** (1500px+ per subject)

Also need:
- **Background scene** (historical painting style preferred, or complex environment)

### Challenge Tasks

Complete all tasks for unified color harmony:

## Task 1: Color Analysis and Strategy

Before any adjustments:

1. **Sample colors** from each source:
   - Skin highlights, midtones, shadows
   - Overall color temperature
   - Saturation levels
   - Dominant color casts

2. **Choose color reference**:
   - Usually the background dictates palette
   - Or choose one subject as reference, match others to it

3. **Document differences**:
   - Which subjects need warming? Cooling?
   - Which need saturation increase/decrease?
   - Which need color cast removal?

4. **Plan adjustment strategy** for each subject

**Success Criteria**:
- [ ] All subjects analyzed with sampled RGB values
- [ ] Background color palette documented
- [ ] Clear adjustment plan for each subject
- [ ] Strategy documented (write it down!)

## Task 2: Individual Color Correction

Match each subject to target palette:

1. **Subject 1**: Apply Curves, Hue/Saturation, Color Balance (clipped to layer)
2. **Subject 2**: Apply appropriate adjustments
3. **Subject 3**: Apply appropriate adjustments

**Focus on**:
- Matching color temperature across all subjects
- Matching saturation levels
- Removing any color casts
- Maintaining natural skin tones

**Success Criteria**:
- [ ] Each subject adjusted individually
- [ ] Non-destructive adjustment layers used
- [ ] Skin tones natural (no orange, gray, or pink)
- [ ] Clear improvement from original

## Task 3: Relative Color Matching

Subjects matched to each other:

1. Place all subjects on background
2. View together at normal size
3. Compare subjects side-by-side:
   - Do they share color temperature?
   - Do they share saturation levels?
   - Do highlight colors match?
   - Do shadow colors match?

4. Refine adjustments until harmonious

**Success Criteria**:
- [ ] All subjects share color family
- [ ] No subject stands out as color-mismatched
- [ ] Highlights harmonize across subjects
- [ ] Shadows harmonize across subjects

## Task 4: Background Integration

Match subjects to environment:

1. Sample background colors (various areas)
2. Compare to subject colors
3. Add additional adjustments to push subjects toward background palette:
   - If background warm: Add warmth to subjects
   - If background has color cast: Add subtle cast to subjects
   - If background desaturated: Desaturate subjects

4. Create environmental color contamination (optional but recommended):
   - Subjects pick up color from surroundings
   - Paint subtle background color along subject edges
   - Very low opacity (5-10%)

**Success Criteria**:
- [ ] Subjects fit background color palette
- [ ] Color temperature consistent with environment
- [ ] Subjects feel "lit by" the environment
- [ ] Optional: Environmental color contamination applied

## Task 5: Unified Color Grading

Final pass for cohesion:

1. Create global Color Lookup or Curves adjustment above all elements
2. Apply subtle unified treatment:
   - Slight color cast for mood
   - Fine-tune overall temperature
   - Final saturation adjustment
   - Add grain/texture if needed for unity

2. This is like film color grading—ties everything together

**Success Criteria**:
- [ ] Global adjustment applied
- [ ] Enhances unity without destroying individual corrections
- [ ] Creates cohesive final look
- [ ] Subtle enough to be invisible

## Overall Success Criteria

Challenge complete when:

- [ ] All subjects have matched color temperature
- [ ] All subjects have matched saturation levels
- [ ] Skin tones are natural across all subjects
- [ ] Subjects harmonize with background
- [ ] No subject stands out as color-mismatched
- [ ] Composite looks like single photograph/painting
- [ ] Color matching invisible at normal viewing distance
- [ ] Quality holds up at high magnification
- [ ] Passed "glance test"—looks unified at first glance
- [ ] Completed in under 50 minutes

**Excellent (90-100%)**:
- Perfect color harmony across all elements
- Indistinguishable from single-source image
- Professional color grading quality

- Background integration seamless
- Could be portfolio piece

**Good (75-89%)**:

- Mostly looks unified
- Skin tones natural

- Obvious color mismatches
- Subjects don't harmonize
- Skin tones problematic
- Doesn't look unified
- Requires significant additional work

## Common Issues and Solutions

### Issue: "One subject still looks off"
**Solution**: That subject likely needs more aggressive correction. Check if you're correcting shadows AND highlights, not just midtones.

### Issue: "Everything looks gray/desaturated"
**Solution**: Over-corrected saturation. Desaturate less, or add back saturation selectively.

### Issue: "Can't get warm enough/cool enough"
**Solution**: Use Blue channel in Curves more aggressively. Also try Color Balance in highlights/shadows separately.

### Issue: "Lost skin tone realism"
**Solution**: Backed yourself into corner with extreme adjustments. Start over with more subtle corrections, multiple layers.
