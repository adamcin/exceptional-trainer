# Module Assessment: Blending & Compositing

Pass 9/11 criteria (82%) to proceed to Module 5.

## Assessment Criteria

### 1. Blend Mode Knowledge
**Task**: Explain and demonstrate Multiply, Screen, Overlay, Soft Light, and Color blend modes.
**Success Criteria**: [ ] Can explain use cases, [ ] Can apply appropriately, [ ] Understand results
**Pass/Fail**: _____

### 2. Shadow Creation
**Task**: Create realistic cast shadow for composited subject.
**Success Criteria**: [ ] Correct direction, [ ] Appropriate softness, [ ] Realistic opacity, [ ] Multiply blend used
**Pass/Fail**: _____

### 3. Contact Shadow
**Task**: Create contact shadow where subject meets surface.
**Success Criteria**: [ ] Present and visible, [ ] Darkest part of shadow, [ ] Grounds subject
**Pass/Fail**: _____

### 4. Shadow Color
**Task**: Create colored shadow (not pure black) matching environment.
**Success Criteria**: [ ] Shadow has color, [ ] Matches environment shadows, [ ] Looks natural
**Pass/Fail**: _____

### 5. Edge Highlighting
**Task**: Add edge highlights showing environmental light.
**Success Criteria**: [ ] Correct edges for light direction, [ ] Appropriate intensity, [ ] Screen blend or similar
**Pass/Fail**: _____

### 6. Dodge and Burn
**Task**: Use non-destructive dodge and burn to refine subject lighting.
**Success Criteria**: [ ] 50% gray layer technique, [ ] Soft Light blend, [ ] Enhances dimension
**Pass/Fail**: _____

### 7. Lighting Direction Consistency
**Task**: Ensure subject lighting matches environment light direction.
**Success Criteria**: [ ] Highlights on correct side, [ ] Shadows on correct side, [ ] Matches reference
**Pass/Fail**: _____

### 8. Texture Matching
**Task**: Match subject texture/grain to background.
**Success Criteria**: [ ] Added grain/noise, [ ] Matches background level, [ ] Consistent at 100% zoom
**Pass/Fail**: _____

### 9. Sharpness Matching
**Task**: Match subject sharpness to background sharpness.
**Success Criteria**: [ ] Similar sharpness level, [ ] Not too sharp or soft, [ ] Consistent appearance
**Pass/Fail**: _____

### 10. Complete Integration
**Task**: Create composite where subject fully integrates with environment.
**Success Criteria**: [ ] All previous criteria met, [ ] Shadows + highlights + texture + color, [ ] Looks believable, [ ] Passes glance test
**Pass/Fail**: _____

### 11. Atmospheric Perspective (if applicable)
**Task**: Apply atmospheric perspective for depth if composite has distance.
**Success Criteria**: [ ] Distant elements less saturated/contrasty, [ ] Slight cool shift, [ ] Creates depth illusion
**Pass/Fail**: _____

## Scoring
**Total**: _____ / 11
**Result**: 9-11 = Proceed to Module 5 | 7-8 = Review weak areas | 0-6 = Revisit exercises
